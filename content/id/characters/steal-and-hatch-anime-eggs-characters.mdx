## Alur Kerja Optimal: Temukan, Evaluasi, dan Tempatkan

Untuk memaksimalkan efisiensi selama sesi bermain Anda, ikuti alur penemuan yang terstruktur. Terburu-buru menetaskan telur tanpa memeriksa tag statistik sering kali menyebabkan hilangnya potensi keuntungan.

```
+-------------------------------------------------------------------------+
|                        ALUR PENEMUAN KARAKTER                           |
+-------------------------------------------------------------------------+
|  [1] Amankan Telur Tingkat Tinggi -->  [2] Tetaskan di Pangkalan        |
|                                                     |                   |
|                                                     v                   |
|  [4] Catat Poin Indeks           <--  [3] Baca Tag Rarity, Size & Mutasi|
|         |                                                               |
|         v                                                               |
|  [5] Bandingkan Pendapatan vs. Slot Plot Aktif Terendah                 |
|         |                                                               |
|         +--> Pendapatan Lebih Tinggi? --> Pasang di Plot (Kunci Area)   |
|         +--> Pendapatan Lebih Rendah? --> Simpan di Tas / Catatan Indeks|
+-------------------------------------------------------------------------+
```

### Langkah demi Langkah Penemuan

1. **Amankan Telur**: Curi tingkat telur yang sesuai dengan kecepatan (Speed) dan kemampuan melarikan diri Anda saat ini.
2. **Lakukan Penetasan**: Kembali ke pangkalan Anda dan segera tetaskan unit tersebut.
3. **Periksa Tag Lengkap**: Periksa nama, tingkat kelangkaan, skala model, dan mutasi yang aktif.
4. **Bandingkan Pendapatan**: Periksa unit aktif Anda yang menghasilkan pendapatan paling rendah. Jika hasil tetasan baru menghasilkan lebih banyak uang per detik, segera tukar posisinya.
5. **Klaim Hadiah Indeks**: Buka menu koleksi dan klaim setiap keuntungan pencapaian (milestone perks) yang terbuka dari penemuan siluet baru.
