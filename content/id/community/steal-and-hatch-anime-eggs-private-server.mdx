## Cara Membuat dan Bergabung dengan Private Server

Menyiapkan dan menjalankan instance privat Anda hanya membutuhkan beberapa klik melalui aplikasi resmi. Jika Anda baru mengenal server VIP, ikuti instruksi di bawah ini untuk mengonfigurasi izin dengan benar di [platform Roblox](https://www.roblox.com).

```
[Halaman Game Roblox] ➔ [Tab Servers] ➔ [Create Private Server] ➔ [Configure Access] ➔ [Undang Whitelist]
```

### Proses Penyiapan Langkah demi Langkah

Ikuti langkah-langkah berikut untuk membangun realm VIP Anda sendiri:

1. **Buka Halaman Game**: Cari game resmi di browser atau aplikasi desktop Anda.
2. **Buka Bagian Servers**: Gulir ke bawah di bawah tombol mainkan dan deskripsi untuk menemukan tab **Servers**.
3. **Buat Instance**: Klik **Create Private Server**. Beri nama realm Anda dengan nama yang mudah diingat.
4. **Konfigurasi Pengaturan**: Klik titik tiga di samping server yang baru dibuat, pilih **Configure**, dan tentukan apakah teman dapat bergabung secara otomatis.
5. **Bagikan Tautan Server**: Jika Anda mengadakan sesi farming tim, buat tautan undangan langsung dan bagikan dengan teman tepercaya Anda.

| Pengaturan Konfigurasi | Pilihan yang Disarankan | Tujuan |
| :--- | :--- | :--- |
| **Server Name** | Kustom (contoh: "Farming Hub") | Identifikasi mudah di antara teman |
| **Allow Friends** | Dinonaktifkan (untuk AFK murni) / Diaktifkan (untuk co-op) | Mencegah gangguan yang tidak diinginkan |
| **Join Link Generation** | Diaktifkan | Akses cepat untuk anggota squad |
| **Subscription Renewal** | Dicentang | Memastikan sesi semalaman tanpa terputus |
